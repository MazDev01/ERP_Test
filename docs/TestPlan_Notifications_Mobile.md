# แผนทดสอบแจ้งเตือนบนมือถือ (iOS / Android) — ERP MAZ

> **ส่งจากคอม → ดูผลบนมือถือ**
> ตัวส่ง: `tools/push-sender.mjs` (รันบนคอมผู้ทดสอบเท่านั้น) · ตัวรับ: ระบบ ERP MAZ บนมือถือ › โปรไฟล์ › แท็บการแจ้งเตือน

## เกณฑ์ผ่าน

**แจ้งเตือนผ่าน = เห็นข้อความ (หัวข้อและเนื้อความ) ขึ้นบนหน้าจอขณะที่มือถือล็อกจออยู่**
ถ้าเห็นแค่คำว่า "การแจ้งเตือน" หรือชื่อแอปอย่างเดียว ให้ถือว่า**ไม่ผ่าน** และตรวจข้อ 2.3 ก่อนสรุปว่าแอปผิด

## 1. ภาพรวม

```
มือถือ ──ลิงก์ trycloudflare──► ตัวส่งบนคอม :3100 ──ส่งต่อ──► ระบบ ERP MAZ :3000
คอม ── http://localhost:3100/__push ──► ตัวส่ง ──► Apple / Google FCM ──► มือถือ
```

- ระบบ ERP MAZ **ไม่มี backend** — ตัวส่งเป็นเครื่องมือทดสอบแยกต่างหาก ปิดโปรแกรมก็หายหมด
- หน้าส่ง `/__push` เปิดได้**จากคอมที่รันตัวส่งเท่านั้น** เปิดผ่านลิงก์ trycloudflare จะได้ 403
- กุญแจและรายชื่อเครื่องเก็บใน `.data/` (ไม่ขึ้น git) ลบโฟลเดอร์ = ทุกเครื่องต้องลงทะเบียนใหม่
- รูปแบบข้อความ (`PushPayload` ใน `src/lib/push-scenarios.ts`) เป็นแบบเดียวกับที่ backend บน Vercel ต้องส่งในอนาคต

## 2. เตรียม

### 2.1 บนคอม (เปิด 3 หน้าต่าง terminal)

```bash
npm run build && npm start          # 1) ระบบ ERP MAZ ที่ :3000
npm run push:sender                 # 2) ตัวส่งที่ :3100
npx cloudflared tunnel --url http://localhost:3100   # 3) ได้ลิงก์ https://….trycloudflare.com ให้มือถือ
```

> ใช้ `npm start` (production) — `npm run dev` จะถูก Next บล็อกเมื่อเปิดผ่านโดเมนอุโมงค์
> ลิงก์ trycloudflare เปลี่ยนทุกครั้งที่รันข้อ 3 ใหม่ · ปิดคอม = ลิงก์ตาย · ใครมีลิงก์ก็เปิดระบบได้

เปิดหน้าส่งบนคอม: **http://localhost:3100/__push**

### 2.3 ตั้งค่ามือถือให้หน้าจอล็อกแสดงข้อความ (ทำก่อนเริ่มทุกเครื่อง)

| ระบบ | ตั้งค่า |
|---|---|
| **iPhone** | การตั้งค่า › การแจ้งเตือน › **ERP MAZ** › เปิด *หน้าจอล็อก* และ *แบนเนอร์* · **แสดงตัวอย่าง › เสมอ** (iPhone ที่มี Face ID ค่าเริ่มต้นคือ "เมื่อปลดล็อก" ซึ่งจะซ่อนข้อความ) · ปิดโหมดโฟกัส |
| **Android** | การตั้งค่า › การแจ้งเตือน › **การแจ้งเตือนบนหน้าจอล็อก › แสดงเนื้อหาทั้งหมด** · การตั้งค่า › แอป › Chrome › การแจ้งเตือน › เปิด · ปิดห้ามรบกวน |

### 2.4 ลงทะเบียนมือถือ

**iPhone** (Safari เท่านั้น)
1. เปิดลิงก์ trycloudflare ใน Safari
2. กดแชร์ › **เพิ่มไปยังหน้าจอโฮม** › เพิ่ม
3. ปิด Safari แล้ว**เปิดจากไอคอน ERP MAZ** (ข้ามไม่ได้ iOS บังคับ)
4. เข้าสู่ระบบ › **โปรไฟล์** › แท็บ **การแจ้งเตือน** › การ์ด **การแจ้งเตือนบนเครื่องนี้**
5. ตั้งชื่อเครื่อง เช่น "iPhone 13 ฝ่ายขาย" › กด **อนุญาตและลงทะเบียนเครื่องนี้** › **อนุญาต**
6. การ์ดขึ้น "ลงทะเบียนแล้ว · รับผ่าน Apple"

**Android** (Chrome)
1. เปิดลิงก์ trycloudflare (จะติดตั้งแอปหรือไม่ก็ได้ — ควรทดสอบทั้งสองแบบ)
2. ทำข้อ 4–5 เหมือน iPhone
3. การ์ดขึ้น "ลงทะเบียนแล้ว · รับผ่าน FCM"

บนคอมกด **โหลดใหม่** ที่หน้าส่ง — ต้องเห็นชื่อเครื่องในรายการ

## 5. อ่านผลการส่งบนคอม

| รหัส | ความหมาย | ทำอะไรต่อ |
|---|---|---|
| **201** | Apple/Google รับไปแล้ว | ถ้ามือถือไม่ขึ้น → ตรวจข้อ 2.3 · ปิดโฟกัส · ตรวจเน็ตมือถือ |
| 400 / 403 | กุญแจหรือรูปแบบไม่ถูก | ลบ `.data/` รันตัวส่งใหม่ แล้วลงทะเบียนมือถือใหม่ |
| 404 / 410 | เครื่องยกเลิกแล้ว | ตัวส่งลบให้อัตโนมัติ — ลงทะเบียนใหม่ถ้าต้องการ |
| 413 | ข้อความยาวเกิน | ย่อข้อความ |
| 0 | คอมต่อ Apple/Google ไม่ได้ | ตรวจเน็ตของคอม |

## 6. ข้อจำกัดที่รู้แล้ว

| เรื่อง | iOS | Android |
