# ERP MAZ

ระบบ ERP งานขายและงานบุคคลของ MAZ — Next.js 16 (App Router + Turbopack), Tailwind v4

```
src/
├─ app/          หน้าและเส้นทาง (route)
├─ components/   ชิ้นส่วนหน้าจอ
└─ lib/          ข้อมูล ตรรกะ และสโตร์ที่เก็บลงเครื่อง
```

## เริ่มงาน

```bash
npm install
npm run dev      # http://localhost:3000
```

## ตรวจก่อนส่ง

```bash
npx tsc --noEmit
npx eslint .
npm run build
```

## ขอบเขตตอนนี้

- **ยังไม่ต่อ backend** ทุกหน้าใช้ข้อมูลจำลอง + `localStorage`
- เป็นมุมของ **พนักงานมองงานตัวเอง** เท่านั้น ยังไม่มีฝั่งหัวหน้า/ผู้อนุมัติ
  รายการจึงค้างที่ "รออนุมัติ" ตามตั้งใจ ไม่ใช่บั๊ก
- แบ่งงานเป็นสองฝ่ายในเมนูซ้าย — **งานขาย** (ลูกค้า คำขอก่อนการขาย ใบเสนอราคา ดีล รายงาน)
  และ **ของฉัน** ซึ่งเป็นฝั่งบุคคล (ตอกบัตร บันทึกเวลา ลา โอที เบิกค่าใช้จ่าย โปรไฟล์)
