# หน้าประวัติรอบ (hr-cycles) — โครงใหม่

## แถบขั้นตอน (เหมือนเดิม)
ตรวจเวลาทำงาน · คำนวณเงินเดือน · ออกสลิปเงินเดือน · **ประวัติรอบ** (ขั้นที่เปิดอยู่เป็นพื้นขาวขอบแดง)
ทุกลิงก์พาเดือนที่เลือกไปด้วย `?m=YYYY-MM`

## แท็บ: รอบรายเดือน / รอบรายวัน
แสดงเฉพาะรอบที่ **ปิดการคำนวณเงินเดือนของกลุ่มนั้นแล้ว** (รอบที่ยังไม่จบไม่ใช่ประวัติ) เรียงรอบล่าสุดไว้บน

ตารางรอบรายเดือน: รอบ · ช่วงวันที่ · ปิดรอบเมื่อ · จำนวนคน · ยอดจ่ายสุทธิ (บาท) · ปุ่ม `เปิดรอบนี้`
ตารางรอบรายวัน: เพิ่มคอลัมน์ **วันที่มาทำงาน (วัน)** ก่อนยอดจ่ายสุทธิ
- ยอดที่แสดงคือยอดที่ **บันทึกไว้ตอนปิดรอบ** ไม่ใช่คำนวณใหม่ (เงินเดือนอาจเปลี่ยนภายหลัง ตัวเลขย้อนหลังต้องนิ่ง)
- กดที่แถวเพื่อเปิดกล่องสรุปยอด ปุ่ม "เปิดรอบนี้" ทำงานของตัวเองไม่เปิดกล่อง

## กล่องสรุปยอดที่ปิดรอบ (ของใหม่)
หัวกล่อง: `สรุปยอดเงินเดือน <เดือน> — พนักงานรายเดือน` หรือ `— ทดลองงาน จ่ายรายวัน`
1. **แถบสถานะ**: จุดเขียว + "ปิดรอบแล้ว" + คั่นจุด + "ปิดเมื่อ <วันที่>" (ยังไม่ปิด = จุดเทา)
2. จำนวนพนักงาน (+ วันที่มาทำงานรวม ถ้าเป็นกลุ่มรายวัน)
3. **ส่วน "รายได้"** หัวข้อมีแถบแดงเล็กนำหน้า — เงินเดือน/ค่าจ้าง · ค่าล่วงเวลา · Commission · Incentive · ค่าตำแหน่ง · รายการปรับปรุง (บรรทัดไหนเป็น 0 ไม่ต้องแสดง)
4. **ส่วน "ประกันสังคม / หัก"** แถบนำหน้าสีน้ำเงิน — ประกันสังคมหัก · นำส่งประกันสังคม (= หัก x2 รวมส่วนบริษัท)
5. **แถบยอดสุทธิ** พื้นเขียวอ่อน ไอคอนถูก + "ยอดจ่ายสุทธิ" ซ้าย ตัวเลขใหญ่ 21px ขวา

# หน้าออกสลิปเงินเดือน (hr-payslip) — จุดที่ต้องมี

## แถบบน
เลือกเดือนด้วยปุ่มซ้าย/ขวา (เลื่อนได้เฉพาะรอบที่มีจริง เดือนแรก/สุดท้ายกดต่อไม่ได้) + แถบขั้นตอน

## แท็บสองกลุ่ม พร้อมจำนวน
`สลิปรายเดือน N` / `สลิปรายวัน N` — **ปุ่มจัดการอยู่แถวเดียวกับแท็บ ชิดขวา** และสลับตามแท็บที่เปิดอยู่
ปุ่ม: `สร้างสลิป` (ปุ่มรอง) + `เผยแพร่` (ปุ่มทึบ ซึ่งเปลี่ยนเป็น `ยกเลิกการเผยแพร่` เมื่อเผยแพร่แล้ว)

ตารางรายเดือน: พนักงาน · ประเภท · รวมรายได้ · รวมรายการหัก · ยอดสุทธิ · สถานะสลิป · จัดการ
ตารางรายวัน: พนักงาน · อัตรารายวัน · วันที่มาทำงาน · ค่าจ้าง · รวมรายการหัก · ยอดสุทธิ · สถานะสลิป
- หัวคอลัมน์ที่เป็นเงินมีบรรทัดเล็กใต้ชื่อว่า `(บาท)`
- สถานะสลิป 3 แบบ: ยังไม่ได้สร้าง (เทา) · สร้างแล้ว รอเผยแพร่ (ส้ม) · เผยแพร่แล้ว (เขียว)
- ปุ่มแก้ไขในคอลัมน์จัดการ **หายไปเมื่อเผยแพร่แล้ว**
- ถ้ารอบเงินเดือนของกลุ่มนั้นยังไม่ปิด ทั้งตารางแทนที่ด้วยข้อความ "รอบเงินเดือนของกลุ่มนี้ยังไม่ปิด จึงยังสร้างสลิปไม่ได้" + ลิงก์ไปหน้าคำนวณเงินเดือนของเดือนนั้น
- กดที่แถวเปิดตัวอย่างสลิป และนับจำนวนครั้งที่เปิดดู/ดาวน์โหลด (แสดงมุมล่างซ้ายของกล่อง)

## กล่องเผยแพร่ / ยกเลิกการเผยแพร่ (ของใหม่)
รายการคู่ป้าย-ค่า: รอบการจ่าย · ช่วงวันที่ · กลุ่มพนักงาน · (ตอนเผยแพร่) จำนวนสลิป + สร้างเมื่อ · (ตอนยกเลิก) เผยแพร่เมื่อ
แล้วต่อด้วย **กล่องข้อความมีไอคอน**
- ตอนเผยแพร่ พื้นฟ้า: "เผยแพร่แล้วพนักงานเรียกดูสลิปของตนเองได้ทันที และระบบแจ้งเตือนทุกคน"
- ตอนยกเลิก พื้นแดงอ่อน: "ยกเลิกการเผยแพร่แล้วพนักงานจะเรียกดูไม่ได้ ต้องแก้ที่การคำนวณเงินเดือนแล้วสร้างและเผยแพร่ใหม่" + **ช่องเหตุผลบังคับกรอก**
