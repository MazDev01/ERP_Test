# หน้าข้อมูลพนักงาน — โครงใหม่ (แทนตารางเดิม)

เดิมเป็นตารางแถวต่อคน ของใหม่เป็น **รายการการ์ด แยกกลุ่มตามประเภทพนักงาน**

## แถบหัวเรื่อง
`ข้อมูลพนักงาน` + ตัวกรอง 4 ช่องเรียงแนวนอน (ค้นหา / แผนก / ตำแหน่ง / สถานะ) + ปุ่มทึบ `+ เพิ่มพนักงาน`
- ตำแหน่งในตัวกรองเปลี่ยนตามแผนกที่เลือก ถ้าเลือกคู่ที่ไม่มีอยู่จริงให้รีเซ็ตเป็น "ทุกตำแหน่ง"
- คำที่ค้นหาต้องถูกไฮไลต์ในชื่อ

## รายการ — กลุ่มพับได้ (`<details>`)
สามกลุ่มตามลำดับ: พนักงานประจำ (จุดสีเขียว) · ทดลองงาน (ส้ม) · ฝึกงาน (น้ำเงิน)
หัวกลุ่ม: จุดสี + ชื่อกลุ่ม + `(N คน)` + ลูกศรหมุนเมื่อเปิด
- กลุ่มที่ไม่มีคนไม่ต้องแสดง
- จำสถานะเปิด/ปิดของแต่ละกลุ่มไว้ข้ามการวาดใหม่
- ถ้ามีการค้นหา/กรองอยู่ ให้เปิดทุกกลุ่มที่มีผลลัพธ์

## การ์ดหนึ่งคน (แนวนอน 3 ส่วน)
1. **รูป 88x88** มุมมน ถ้าไม่มีรูปให้เป็นกรอบเทาว่างพร้อมไอคอนคนและคำว่า "ยังไม่มีรูป" (ห้ามเอารูปคนอื่นมาแทน)
2. **ข้อมูล** — ชื่อเต็ม (ตัวหนา 16px) + ป้ายสถานะ (ปฏิบัติงานอยู่ = เขียว / พ้นสภาพ = เทา) · บรรทัดตำแหน่ง · บรรทัดแผนก (เล็กกว่า จางกว่า) · แถวชิป
   - ชิปเสมอ: `เริ่ม <วันที่ไทย>` และ `ทำงานมาแล้ว X ปี Y เดือน` (คนพ้นสภาพใช้คำว่า "ทำงานรวม")
   - ชิปเพิ่มเมื่อทดลองงาน: `ครบกำหนดอีก N วัน` (ส้ม) หรือ `เลยกำหนดทดลองงาน N วัน` (แดง)
   - ชิปเพิ่มเมื่อพ้นสภาพ: `พ้นสภาพ <วันที่>` (แดง)
3. **ขวาสุด กว้าง 110px** — ทดลองงานที่ยังทำงานอยู่: **วงแหวน donut** บอก % ที่ผ่านช่วงทดลองงาน (คิดจากวันที่ผ่านมาเทียบระยะทดลองงาน ไม่ใช่คะแนนผลงาน) สีไล่จากแดง→ส้ม→เขียวตาม % ใต้วงเขียน "ผ่านช่วงทดลองงาน" · คนอื่นแสดงแค่ข้อความประเภทพนักงาน
- คนพ้นสภาพ การ์ดจางลง (opacity .62)
- ทั้งการ์ดกดได้ และใช้คีย์บอร์ดได้ (tabindex)
- มือถือ: การ์ดตกบรรทัด รูปเหลือ 64x64 ส่วนขวาเรียงเป็นแถวเต็มความกว้าง

## กล่องรายละเอียด (เปิดจากการ์ด) — แบบหน้าโปรไฟล์
- **แบนเนอร์แดงไล่สี** สูง 78px มีวงกลมจาง ๆ ประดับ + ปุ่มปิดมุมขวาบนบนแบนเนอร์
- **รูป 80x80** ขอบขาว 3px เงานุ่ม ลอยขึ้นมาทับแบนเนอร์ (margin-top ติดลบ) ข้าง ๆ เป็นชื่อ + ป้ายสถานะ
- **แถบข้อมูล 4 ช่อง** (แผนก / ประเภทพนักงาน / อีเมล / โทรศัพท์) เป็นกล่องเทาอ่อน — มือถือเหลือ 2 คอลัมน์
- **แท็บ 5 อัน**: Overview · ข้อมูลส่วนตัว · ข้อมูลงาน · เอกสาร · เงินเดือน
  - Overview: 2 คอลัมน์ "สรุปการจ้างงาน" กับ "สรุปส่วนตัว"
  - ข้อมูลส่วนตัว: ประวัติส่วนตัว (รวมวุฒิ/ประสบการณ์เป็นรายการ) + ข้อมูลติดต่อ (รวมผู้ติดต่อฉุกเฉิน)
  - ข้อมูลงาน: ข้อมูลการจ้างงาน + สถานะการทำงาน (ทดลองงานมีบรรทัด "ครบกำหนดทดลองงาน" พร้อมเหลือ/เลยกี่วัน)
  - เอกสาร: รายการเอกสารพร้อมวงกลมสถานะ เขียว=มี แดง=บังคับแต่ยังไม่มี เทา=ไม่บังคับ ท้ายรายการสรุปว่าขาดกี่รายการ
  - เงินเดือน: ตารางประวัติตำแหน่ง+เงินเดือน เรียงใหม่สุดบน (วันที่มีผล / ตำแหน่ง / เงินเดือน / หมายเหตุ)
- แต่ละ section เป็นกล่องพื้นเทาอ่อนมีขอบ หัวข้อสีแดงตัวเล็ก
- ทดลองงานที่ยังทำงานอยู่: มีกล่องอธิบายว่า "ตอนนี้จ่ายค่าจ้างรายวัน ผ่านทดลองงานแล้วจะเปลี่ยนเป็นพนักงานประจำจ่ายรายเดือน" + ปุ่มทึบ **บันทึกผ่านทดลองงาน**

## กล่อง "บันทึกผ่านทดลองงาน"
แสดงของเดิม (ประเภทตอนนี้ = ทดลองงาน/จ่ายรายวัน · อัตราที่บันทึกไว้ · ครบกำหนดทดลองงาน)
แล้วให้กรอก **วันที่มีผล** กับ **เงินเดือนรายเดือน** (ต้องกรอกเอง ห้ามเอาอัตรารายวันเดิมมาใช้ต่อ เพราะคนละความหมาย)
มีบรรทัดพรีวิว "หลังมีผล จะคิดเงินเดือนรายเดือน X บาท (ค่าจ้างรายชั่วโมงสำหรับโอที Y บาท)"
ยืนยันแล้ว: เปลี่ยน type เป็น full และ **เพิ่มแถวประวัติใหม่** ไม่เขียนทับของเดิม

## กล่อง "เพิ่มพนักงาน"
แบ่ง 5 ส่วนมีหัวข้อและเส้นคั่น: ข้อมูลตัวบุคคล · การจ้างงาน · การติดต่อ · ผู้ติดต่อฉุกเฉิน · เอกสารที่ได้รับแล้ว (เช็กบ็อกซ์ 2 คอลัมน์ ติดดอกจันแดงถ้าบังคับ)
- ประเภทการจ้างตั้งต้น = ทดลองงาน (ทุกคนเริ่มแบบนี้)
- ตรวจก่อนบันทึก: ต้องมีชื่อและนามสกุล, วันเริ่มงาน, เงินเดือน, เบอร์โทร, และเตือนถ้าชื่อซ้ำกับคนในระบบ
- บันทึกแล้วเลื่อนจอไปที่การ์ดของคนที่เพิ่งเพิ่ม
